# 실험 예제

UI 왼쪽 하단의 `저장한 시나리오 JSON 경로`에 파일의 전체 경로를 입력한 후 `지정 파일 / 실제 이동 기록 불러오기`를 누릅니다.

| 파일 | 내용 |
|---|---|
| `01-crossing.json` | 열린 5×5 지도에서 서로 마주 오는 두 에이전트. 독립 A*의 충돌 원래 계획 포함. 실행하면 이동 전 정지와 자동 복구를 관찰할 수 있습니다. |
| `02-bottleneck.json` | 12×12, 8명, 병목 2개·통로 폭 3. Cooperative A*를 실행해 비교합니다. |
| `03-random-32.json` | 32×32, 32명, 요청 장애물 밀도 20%, 지도 시드 23·배치 시드 42. 모든 에이전트 표시와 부분 계획 처리를 살펴볼 수 있습니다. |
| `profile.json` | 거리·혼잡·협소도를 사용하는 Cooperative 우선순위 설정 예제. 데이터 폴더의 `profile.json`으로 복사 후 프로필 불러오기로 적용합니다. |
| `crossing-results.csv` | 위 5×5 사례를 C# 회귀 실행 환경(.NET 10)에서 실제 계산한 세 알고리즘 원시 결과. Unity 성능 측정값이나 대규모 벤치마크가 아닙니다. |

예제는 회귀 도구가 실제 직렬화 코드로 생성하고 다시 읽어 검사합니다. JSON의 장애물·시작·목표 좌표가 시나리오의 기준이며, 파일 불러오기만으로 지도 재생성을 수행하지 않습니다. 시드 재생성을 누르면 선택한 생성 규칙에 따라 새 지도가 만들어집니다.
