# 공개 PRIMAL 모델 연결

이 어댑터는 [원저자 PRIMAL 저장소](https://github.com/gsartoretti/PRIMAL)의 `ACNet`과 `mapgenerator.observe()`를 호출합니다. 학습 가중치를 규칙 기반 경로 탐색으로 대체하지 않습니다. 원본의 TensorFlow 1.x 환경을 Unity 및 일반 Python 환경에서 분리합니다.

## 준비

1. 원저자 저장소를 별도 폴더로 내려받습니다.
2. 저장소 README의 공개 학습 모델 링크에서 체크포인트를 받아 `model_primal` 폴더에 풉니다. `checkpoint`, `.index`, `.data-*` 파일이 필요합니다.
3. Conda가 있다면 이 폴더에서 `conda env create -f environment.yml`로 격리 환경을 구성합니다. 제공 파일은 TF 1.15 호환 환경 구성안이며 이 PC에서 모델 추론까지 검증된 환경은 아닙니다. 원저자는 더 오래된 Python/TF 버전을 명시합니다.
4. `config.example.json`을 `config.json`으로 복사하고 저장소와 모델 폴더의 실제 경로를 넣습니다.
5. Unity에서 PRIMAL을 선택하고 Python에는 격리 환경의 `python.exe`, 어댑터에는 이 폴더의 `primal_adapter.py`를 지정합니다.

## 동작과 비교 조건

- 모델의 4채널 10×10 관측, 목표 벡터, 5개 행동 확률, 선택 행동을 JSON으로 반환합니다.
- 같은 시드에서 argmax 행동을 선택합니다. 개별 에이전트의 recurrent state를 유지합니다.
- 목표에 도착한 에이전트는 영구 점유합니다. 정적 장애물로의 행동은 대기로 기록합니다.
- 공동 행동에서 정점/간선 충돌이 예상되면 해당 이동 전에 rollout을 중지하고 실패 이유를 반환합니다. 따라서 원저자 데모의 순차 이동 실행 결과와 동일한 벤치마크라고 해석하면 안 됩니다.
- 모델 출처와 체크포인트 인덱스 SHA-256을 기록합니다. 직접 학습한 모델로 표시하지 않습니다.
- 실패 시 원시 관측·행동 로그도 유지합니다. Unity의 자동 복구/CBS 대체를 사용한 결과는 원래 모델 성공률과 분리합니다.

모델 파일은 이 프로젝트에 포함되지 않습니다. 현재 PC에는 호환 TF 환경과 체크포인트가 없어 실제 학습 모델 추론은 미검증입니다. 현재 Python에서 어댑터의 JSON 실패 응답과 문법은 검증할 수 있습니다.
